# API Key Setup Guides

Step-by-step guides for every API key mentioned in the main [README](../../README.md#api-keys). You only strictly need one of OpenAI or Gemini to run AutoFLUKA at all, everything else is optional.

Prefer a slide-by-slide walkthrough instead? See the same steps as a [PDF deck](../API_Key_Setup_Guides.pdf).

| Guide | Required? | Free? |
|---|---|---|
| [OpenAI](openai.md) | One of OpenAI or Gemini | No, requires billing |
| [Gemini](gemini.md) | One of OpenAI or Gemini | Yes |
| [Tavily](tavily.md) | Optional, live web search | Yes |
| [Hugging Face](huggingface.md) | Optional, document parsing | Yes |
| [LangSmith](langsmith.md) | Optional, tracing/logs | Yes |
| [Google Custom Search](google-custom-search.md) | Optional legacy backup, most new users should skip this one | Only if you already have access |
